이름부터 알려주세요

여행 기록에 표시할 이름이나 별명이면 충분해요.

이 기기에서 이름을 기억합니다. 이름은 표시용이며, 같은 이름을 쓴 다른 사람과 기록이 공유되지 않습니다.

어디까지 떠나볼까요?

선택한 시·도 안에서 추첨해요. 세종과 제주도 포함합니다.

이용 안내

  1. 이름 입력 후 시작

    처음 방문하면 이름이나 별명을 입력합니다. 이름은 이 기기에서 기억합니다.

  2. Enter로 시·도, 시·군·구 확정

    추첨을 시작한 뒤 Enter를 누르면 보이던 지역이 확정됩니다. 시·도 확정 1.2초 뒤 하위 추첨이 시작돼요. 키를 뗐다가 다시 눌러주세요. 누르지 않으면 각 단계가 5초 뒤 자동으로 멈춥니다.

  3. 예외 지역과 확률

    세종은 시·도 선택으로 완료하며, 제주는 제주시·서귀포시를 추첨합니다. 일반구는 시 단위로 합치고 섬도 포함합니다. 선택 시·도끼리 균등, 그 안의 목적지끼리 균등 확률입니다. 중복은 허용합니다.

  4. 원하는 결과만 기록

    추첨만 하면 임시 목록에 모입니다. 결과 하나를 바로 기록하거나 여러 개를 체크해 기록하세요. 이름을 변경해도 기존 기록의 이름은 바뀌지 않습니다.

  5. 이름과 저장 범위

    이름은 로그인 계정이 아닙니다. 같은 브라우저에서 이름을 바꾸면 기존 기록은 계속 보입니다. Firebase 연결 후에는 선택 기록만 익명 사용자 ID별로 저장합니다. 다른 기기에서 같은 이름을 입력해도 기록을 공유하지 않으며 브라우저 데이터 삭제 시 접근이 끊길 수 있습니다.
