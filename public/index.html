어디까지 떠나볼까요?

선택한 시·도 안에서만 추첨합니다. 예외 지역도 포함돼요.

우연을 만나는 방법

  1. 시작 → Enter

    이름이 돌다가 Enter를 누르는 순간 보이던 시·도가 확정됩니다.

  2. 시·군·구 → Enter

    1.2초 뒤 하위 지역 추첨이 시작됩니다. 키를 뗐다가 다시 눌러 최종 목적지를 정하세요.

  3. 예외 지역도 빠짐없이

    세종은 시·도 선택으로 완료합니다. 제주는 제주시·서귀포시를 추첨하고, 일반구는 시 단위로 합칩니다. 섬 지역도 포함합니다.

  4. 확률과 기록

    선택한 시·도끼리 동일 확률, 그 안의 목적지끼리 동일 확률입니다. 전국 모든 목적지의 확률이 같지는 않습니다. 연속 중복은 허용합니다.

  5. 내 기록 저장

    Firebase 연결 후 익명 사용자별로 저장합니다. 다른 기기·브라우저에서는 동일 기록을 볼 수 없으며 브라우저 데이터 삭제 시 접근이 끊길 수 있습니다. 저장 실패는 임시 보관 후 재시도합니다.

지도는 여행지 선정용입니다. 이동 가능 여부와 교통편은 출발 전에 확인해주세요.
