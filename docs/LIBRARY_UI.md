# UI 라이브러리 전환 · 2026-11-10

## 요청과 원인 확인

사용자는 이전 색상이 비슷하게 반복되는 점을 지적하고 색상 강제 설정이 있으면 제거한 뒤 라이브러리로 UI를 꾸미도록 요청했다. 후속으로 안 되는 부분이 있는 것 같으니 완료 상태를 확인해달라고 했다.

프로젝트 안의 설정·CSS·결정 문서를 검색했다. 별도 서비스나 외부 config가 특정 색을 강제하는 구조는 없었고, 제작자가 작성한 style.css와 theme.css에 같은 계열의 값이 중복돼 있었다. 기존 두 CSS의 내용은 폐기하고 theme.css 파일과 참조를 제거했다. README와 결정 문서의 이전 색상 선택도 현행 지침에서 제외했다. 과거 검증 문서는 당시 이력으로 보존하며 현재 디자인 제약으로 사용하지 않는다.

## 변경

- Bootstrap 5.3.8, Bootstrap Icons 1.13.1을 정확한 버전으로 설치하고 package-lock.json에 고정.
- Bootstrap 그리드·버튼·폼·배지·목록을 실제 HTML과 동적 목록에 적용.
- 문자 아이콘을 라이브러리 아이콘 폰트로 교체. 앱 아이콘은 공식 compass-fill SVG의 색만 조정.
- 흰 배경, 밝은 회색 지도, 짙은 회색 추첨 패널, 파란 주요 버튼으로 재구성. 지도 목적지는 별도 강조색을 사용.
- 의미별 변수 accent/ink/surface/border로 새 단일 style.css를 작성. green/mint/paper 등 이전 변수 및 theme.css 참조 제거.
- Bootstrap 자산·아이콘 폰트·MIT 라이선스를 빌드 시 dist/vendor/에 복사하여 외부 CDN 없이 제공.
- GitHub Actions에 npm ci와 npm 캐시를 추가하여 깨끗한 환경에서도 자산을 빌드.
- 최종 목적지가 확정되면 해당 목적지 경계에 맞춰 지도 확대. 이름 입력·선택 기록·예외 지역·기록 소유권 구조는 유지.

변경 파일: package.json, package-lock.json, scripts/build.mjs, .github/workflows/pages.yml, public/index.html, public/style.css, public/favicon.svg, src/app.js, README 및 관련 결정·검증 문서. public/theme.css는 제거했다. 사용자 기록과 Firebase 설정·규칙은 바꾸지 않았다.

## 화면 확인과 제한

로컬 미리보기를 127.0.0.1:5178에서 실행했다. 자동 브라우저의 페이지 열기는 자동 승인 검토 서비스가 503 Service Unavailable을 반환하여 차단됐다. 사용자 거절이나 앱 오류로 확정된 결과가 아니다. 다른 브라우저·직접 CDP 등으로 우회하지 않았다.

사용자에게 직접 로컬 주소를 열었을 때의 표시를 확인했고 **“파란 버튼과 짙은 회색 추첨 패널이 보여요”**라는 답변을 받았다. 이는 사용자에 의한 기본 화면 표시 확인이며, 에이전트의 자동 브라우저 전체 조작·반응형 검수나 캡처를 수행한 것으로 계산하지 않는다.

기능 자동 검사와 자산 검사는 통과했으며, 이름 입력·추첨·선택 기록의 새 UI 전체 조작 검수는 자동 브라우저 승인 서비스가 복구된 후 확인할 수 있다. Firebase 실제 연결은 여전히 공개 웹 설정 수령 대기다.

## 현재 UI 구성

과거 색상은 의무 사항이 아니며 새 팔레트도 변경 가능한 제작 선택이다. 새 UI는 배포해 사용자가 테스트할 수 있으며, 자동 브라우저 미검증 범위를 보고에 유지한다.
