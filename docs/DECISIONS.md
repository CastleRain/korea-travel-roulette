## 이전 색상·서체 보완 이력 · 현재 색상 지침 아님

사용자가 AI 같은 느낌을 줄이도록 UI 분석을 요청한 뒤 색상·서체를 다듬고 Firebase 연결 방법을 알려달라고 했다. 기존 구조와 추첨 규칙을 유지하며 다음을 적용했다.

- 당시 제작자가 선택했던 색상 테마는 이후 사용자 요청으로 폐기했다. 특정 색상 사용을 강제하는 지침으로 재사용하지 않는다.
- 공식 Pretendard v1.3.9 Variable 글꼴 자체 호스팅, 라이선스 동봉.
- 장식 스탬프·지도 문구·중복 영문·하단 슬로건 제거, 티켓 장식 단순화.
- 제목의 크기·굵기를 낮추고 실제 목적지·한글 설명의 위계를 강화. 일반 보조 글자 12~14px 중심.
- 기존 2열 구조와 모바일 추첨 카드 우선 순서 유지. 기존 데이터·기록 보존.
- `docs/FIREBASE_SETUP.md`에 기존 프로젝트를 위한 콘솔 설정·규칙 병합·공개 웹 설정·실제 문서 검증 순서를 제공.

실제 Firebase 프로젝트의 설정·권한을 변경하는 요청은 이번에는 연결 방법 안내 범위이며, DB 연결 완료로 표시하지 않는다.

## 첫 방문 이름 및 선택 기록 · 2026-11-10

사용자가 첫 방문 이름 입력과 선택한 결과를 기록에 남기는 기능을 요청했다. 첫 방문에는 1~20자 이름/별명을 입력해야 추첨을 시작할 수 있고 이 기기에서 기억한다. 상단에서 이름을 바꿀 수 있다.

추첨 자체는 로컬 후보(`candidate`)만 만들고, 결과 단건 기록 또는 목록에서 선택한 여러 결과 기록으로만 저장 대기열에 들어간다. 미선택 결과는 Firebase 연결·재시도 때도 전송하지 않는다. 이름은 추첨 당시 표시값을 각 기록에 보존하고, 소유권은 기존 익명 UID로 유지한다. 이름이 같은 타인의 기록을 공유하지 않으며 같은 브라우저의 이름 변경은 계정 전환이 아니다. 기존 이름 없는 기록을 보존하고 소급 이름 변경을 하지 않는다.

새 필드를 허용하는 Firestore 규칙은 로컬 에뮬레이터에서 확인한다. 실제 Firebase 설정은 계속 수령 대기이며 클라우드 저장 완료를 주장하지 않는다.

## UI 라이브러리 전환 · 2026-11-10

사용자가 같은 계열 색상을 반복한 점을 지적하고, 색상을 강제하는 설정이 있다면 지우고 UI 라이브러리로 꾸미도록 요청했다. 별도 외부 색상 강제 설정은 없었으며 제작자가 작성한 두 CSS에 중복된 색상 값이 있었다. 기존 theme.css와 style.css를 폐기하고 새 단일 style.css 및 Bootstrap 5.3.8 / Bootstrap Icons 1.13.1로 전환한다.

흰 바탕·밝은 회색 지도·짙은 회색 추첨 패널·파란 주요 버튼을 이번 구현 선택으로 사용한다. 색상 의무 지침이 아니며 의미별 변수로 변경할 수 있다. 이름·선택 기록·예외 지역·Firebase 저장 구조는 유지한다. 실제 화면 확인은 브라우저 도구의 자동 승인 검토 서비스 503 오류로 차단됐으며 확인하지 않은 화면을 검수 완료로 판정하지 않는다.

사용자는 로컬 주소를 직접 열어 파란 버튼과 짙은 회색 추첨 패널이 보인다고 확인했다. 기본 화면 표시는 사용자 확인으로 구분하며, 기능 검사 28개·정적 자산/ID 검사를 통과한 새 UI를 배포한다. 자동 브라우저 전체 조작·모바일 검수는 미실행 상태로 유지한다.
