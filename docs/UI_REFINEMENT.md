# 색상·서체 보완 및 Firebase 안내 · 2026-11-10

## 범위

사용자가 기존 화면의 AI 같은 인상을 줄이도록 색상과 글씨체를 다듬고 Firebase 연결 방법을 요청했다. 기존 지도·추첨·예외 지역·기록 동작은 보존하고 시각 표현과 안내 문구를 조정했다. Firebase 실연결 요청이나 웹 설정 수령은 아니므로 DB 설정·실저장 완료로 판정하지 않는다.

## 변경

- `public/theme.css`: 실제 웹폰트 정의, 중립색 본문, 초록의 역할 제한, 간결한 카드, 작은 장식 제거, 모바일 글자 크기와 색상.
- `public/fonts/PretendardVariable.woff2`, `OFL.txt`: 공식 Pretendard v1.3.9 Variable 파일과 재배포 라이선스.
- `public/index.html`: 웹폰트 preload와 theme 로드, 스탬프·지도 장식·반복 영문·하단 슬로건 제거, 간결한 한글 제목 및 기록 안내.
- `public/favicon.svg`: 새 강조색으로 맞춤.
- `src/app.js`: 미연결·연결 중·실패를 사용자 관점의 클라우드 저장 상태로 표시. 저장 완료 판정 로직은 유지.
- `scripts/serve.mjs`: 로컬 웹폰트 및 라이선스 MIME 형식 지원.
- `docs/FIREBASE_SETUP.md`, `README.md`, `docs/DECISIONS.md`: 콘솔 연결 안내, 서체 출처·라이선스, 구현 결정.

## 직접 확인

- 기능 검사 `npm.cmd test`: 19/19 통과.
- `npm.cmd run build`: 성공.
- 실제 브라우저에서 `document.fonts.check('500 16px Pretendard')` 결과 true, body의 적용 서체 Pretendard 확인.
- 실제 배경 색 `rgb(247, 245, 240)` 확인.
- 동일 기본 viewport의 변경 전후 전체 화면을 함께 비교. 지도·추첨 배치를 유지하고 장식과 색상·서체가 바뀐 것을 확인.
- 모바일 390×844: DOM 폭 375px로 가로 넘침 없음. 확정 결과의 적용 글자 크기 38px 확인.
- 실제 Enter 1.5초 누르기 후 첫 단계만 확정하고 하위 추첨 진행, 다음 Enter로 경상북도 예천군 확정·기록 생성 확인.
- 모바일 지역 선택 모달에서 모든 지역과 버튼 표시 확인. 긴 시·도 이름은 두 줄로 표시되며 후보가 잘리지 않음.
- 로컬 기존 임시 기록 3개를 유지하고 새 추첨 후 4개가 됨을 확인. 개발 검증 기록이며 실제 Firebase 저장 증거가 아님.

주요 단색 대비 계산은 본문/배경 12.82:1, 보조 설명/카드 5.21:1, 흰 버튼 글자/초록 버튼 8.19:1이다. 정의한 단색 조합의 계산 결과이며 전체 화면 접근성 인증을 뜻하지 않는다. 지도·작은 보조 요소 전체의 대비 및 보조기기 검사는 이번 범위에서 수행하지 않았다.

보안 규칙·Firebase SDK 저장 로직은 변경하지 않아 Firestore 에뮬레이터 검사를 반복하지 않았다. 이전 5개 에뮬레이터 통과는 최초 검증 기록에 남겼다. 실제 Firebase 프로젝트 연결은 여전히 설정 대기다.

## Firebase 안내의 근거와 다음 단계

2026-11-10 Firebase 공식 웹 설정·익명 인증·Firestore 시작·규칙 배포 문서를 확인해 안내서를 작성했다. 기존 프로젝트는 기본 DB 여부와 기존 규칙을 확인하고 필요한 경로만 병합하도록 설명했다.

웹 앱 공개 설정을 받기 전에는 실제 클라우드 연결·저장 확인을 할 수 없다. 사용자는 안내서의 웹 앱 등록·익명 로그인·Firestore 준비·규칙 적용 순서대로 진행한 뒤 `firebaseConfig`를 연결할 수 있다. 서버 비밀 키나 서비스 계정 인증 파일은 필요하지 않다.
